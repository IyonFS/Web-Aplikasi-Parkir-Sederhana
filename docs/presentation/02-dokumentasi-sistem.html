Deskripsi Program

Hygiopark adalah aplikasi parkir pintar berbasis web dengan struktur yang jelas dan modular.

Sistem ini dirancang untuk membantu pengelolaan slot parkir, reservasi, pembayaran, monitoring aktivitas, serta fitur otomatis seperti waitlist dan recurring booking.

Frontend, backend, dan database dipisah dengan rapi agar project mudah dipahami saat presentasi dan tetap nyaman dilanjutkan ketika masuk tahap pengembangan berikutnya.

Halaman ini cocok dipakai sebagai jembatan antara penjelasan database dan demo fitur, karena isinya menunjukkan bagaimana semua bagian project saling bekerja sama dari tampilan sampai penyimpanan data.

Arsitektur Program

Frontend menjadi lapisan interaksi pengguna, backend menjadi pusat logika dan keamanan, sedangkan database menyimpan data permanen. Pemisahan ini membuat debugging, scaling, dan pembagian tanggung jawab lebih mudah.

Alur Besar Sistem

Frontend React + Vite menangani halaman, form, state global, dan komunikasi API.
Backend Express menangani autentikasi, validasi role, logika reservasi, pembayaran, dan scheduler.
Database Prisma menjadi penghubung antara backend dan PostgreSQL.
Real-time Socket.IO dipakai untuk update status slot dan notifikasi waitlist/recurring.

Titik Masuk Penting

backend/server.js Menyalakan server, koneksi database, socket, dan scheduler.
backend/src/app.js Menyusun middleware, route, rate limiter, dan error handler.
frontend/src/main.jsx Entry frontend React dan root render aplikasi.
frontend/src/app/App.jsx Menyusun router, provider context, dan proteksi halaman.

Alur Kerja Sistem dari Pengguna ke Database

Alur Frontend ke Backend

1. User membuka halaman React Router menentukan halaman dan provider menyiapkan auth, theme, socket, serta notifikasi.
2. User melakukan aksi Misalnya login, memilih slot, membuat reservasi, atau melihat histori.
3. Service frontend memanggil API File di frontend/src/services/ mengirim request ke backend secara terstruktur.
4. Backend memproses Route, controller, service, dan Prisma bekerja sesuai fitur yang dipanggil.

Alur Backend ke Database

5. Validasi dan role dicek Middleware memastikan request aman dan sesuai hak akses.
6. Prisma mengakses PostgreSQL Data dibaca, disimpan, atau diperbarui berdasarkan schema.
7. Response dikirim balik Frontend menerima hasil dan memperbarui tampilan.
8. Socket memperbarui status Perubahan penting dapat disiarkan ke client lain secara real-time.

Fitur, Fungsi, dan Halaman Web

Autentikasi & Role

Login, register, proteksi halaman, dan pembagian akses admin, operator, serta user.

Dashboard

Ringkasan status parkir, statistik cepat, dan jalur menuju modul operasional.

Manajemen Slot

Menampilkan status slot per area, tipe slot, dan aksi perubahan data.

Reservasi Parkir

User memilih slot, menentukan durasi, memperpanjang, membatalkan, dan melihat tiket QR.

Pembayaran

Mendukung mode demo dan integrasi Midtrans dengan invoice, webhook, dan status transaksi.

Waitlist & Recurring

Slot penuh dapat dialihkan ke antrean, dan kebutuhan rutin ditangani dengan booking berulang.

Analytics & Logs

Admin memantau laporan, pendapatan, peak hours, dan aktivitas sistem.

Manajemen Master

Admin mengatur user, area parkir, tarif, kendaraan, dan data pendukung lainnya.

Profil & Notifikasi

User memperbarui data diri dan menerima informasi penting dari sistem.
