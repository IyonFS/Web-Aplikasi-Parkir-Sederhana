Module Pembelajaran

Halaman ini menjelaskan Hygiopark sebagai bahan belajar anak SMK jurusan IT, bukan hanya sebagai aplikasi jadi.

Materi di halaman ini dibuat untuk pemula yang ingin paham bagaimana aplikasi parkir web disusun dari frontend, backend, database, konfigurasi, sampai tools yang membantu proses pengembangannya.

Isinya bukan teori lepas, tetapi langsung dikaitkan dengan file dan logika yang memang ada di project Hygiopark, sehingga pembelajaran terasa lebih konkret dan mudah dipraktikkan ulang.

Dengan pendekatan ini, pengguna bisa melihat bahwa satu aplikasi web sebenarnya adalah gabungan dari banyak konsep dasar: variabel, array, objek, routing, API, database, environment, dan kerja tim.

Library dan Framework yang Dipakai

Library adalah kumpulan fungsi siap pakai, sedangkan framework adalah kerangka kerja yang mengatur cara aplikasi dibangun. Di Hygiopark, keduanya dipakai bersama agar aplikasi parkir lebih cepat dikembangkan dan lebih rapi saat dipelihara.

React

Framework library untuk membangun tampilan frontend berbasis komponen seperti halaman login, dashboard, slot, dan reservasi.

React Router DOM

Mengatur perpindahan halaman di frontend, misalnya dari /login ke /app/dashboard tanpa reload penuh.

Axios

Dipakai frontend untuk mengirim request ke backend, misalnya mengambil data slot, user, reservasi, dan laporan.

Socket.IO

Memberi update real-time, jadi perubahan status slot atau reservasi bisa langsung terlihat tanpa refresh manual.

Express

Framework backend Node.js yang menangani route API, middleware, validasi akses, dan response JSON untuk aplikasi parkir.

Prisma

ORM yang menghubungkan kode JavaScript backend ke PostgreSQL, sehingga query database menjadi lebih aman dan terstruktur.

PostgreSQL

Database relasional utama untuk menyimpan user, lot, slot, reservasi, pembayaran, waitlist, dan log aktivitas.

bcryptjs + jsonwebtoken

Digunakan untuk keamanan login: password di-hash, lalu user yang berhasil login diberi token akses.

Vite + Tailwind + PostCSS

Vite mempercepat development frontend, Tailwind membantu styling, dan PostCSS memproses CSS agar lebih praktis.

Contoh Array dan Looping

Seed database memuat array dan perulangan untuk membuat banyak slot parkir secara otomatis.

const floors = ["A", "B", "C"];
const slotConfigs = [
  { type: "standard", price: 5000 },
  { type: "ev", price: 8000 },
  { type: "disabled", price: 3000 },
];

for (const floor of floors) {
  for (let i = 0; i < slotConfigs.length; i++) {
    const cfg = slotConfigs[i];
    slots.push({
      floor,
      type: cfg.type,
      price: cfg.price,
    });
  }
}

Bagian ini cocok untuk menjelaskan array, object di dalam array, perulangan for, dan cara data diproses satu per satu.

Contoh Percabangan dan Logika

Aplikasi parkir banyak memakai percabangan untuk cek hak akses, token, atau status transaksi.

function authorize(...roles) {
  return (req, res, next) => {
    if (!roles.includes(req.user.role)) {
      return res.status(403).json({ error: "Insufficient permissions" });
    }
    next();
  };
}

Siswa bisa belajar konsep parameter, array rest, method includes(), dan kondisi if untuk keamanan sistem.

Memahami API pada Hygiopark

API adalah jembatan komunikasi antara frontend dan backend. Saat user menekan tombol di halaman web, frontend tidak langsung mengambil data dari database, tetapi mengirim request ke API. Backend kemudian memproses request itu, berkomunikasi dengan database lewat Prisma, lalu mengirim response kembali ke frontend.

Alur kerja API yang sederhana

1. User melakukan aksi misalnya login, melihat slot, atau membuat reservasi dari halaman React.
2. Frontend mengirim request memakai Axios ke alamat API seperti /api/auth atau /api/slots.
3. Backend Express menerima request lalu menjalankan route, middleware, dan service yang sesuai.
4. Prisma mengakses PostgreSQL untuk membaca atau menyimpan data yang dibutuhkan.
5. Backend mengirim response JSON agar frontend bisa menampilkan hasil ke user.

Contoh endpoint utama yang ada

/api/auth untuk login dan autentikasi user.
/api/users untuk data pengguna dan manajemen akun.
/api/slots untuk melihat status slot parkir.
/api/reservations untuk membuat dan melihat reservasi parkir.
/api/payments untuk alur pembayaran.
/api/waitlist untuk antrean saat slot penuh.
/api/recurring untuk booking berulang.
/api/analytics untuk ringkasan dashboard dan laporan.

Contoh kode frontend memanggil API

const rawBaseURL = import.meta.env.VITE_API_URL || "";
const BASE_URL = rawBaseURL ? rawBaseURL.replace(/\/+$/, "") + "/api" : "/api";

const api = axios.create({
  baseURL: BASE_URL,
  headers: { "Content-Type": "application/json" },
});

Kode ini menunjukkan bahwa frontend punya alamat dasar API. Jadi saat frontend ingin login atau mengambil data slot, request akan diarahkan ke backend melalui base URL tersebut.

Contoh struktur route backend

router.use("/users", usersRoutes);
router.use("/slots", slotsRoutes);
router.use("/reservations", reservationsRoutes);
router.use("/payments", paymentRoutes);
router.use("/waitlist", waitlistRoutes);

Dari sini siswa bisa memahami bahwa backend membagi API berdasarkan fitur. Ini membuat project lebih rapi daripada menaruh semua endpoint dalam satu file besar.

Apa isi request dan response?

Request adalah data yang dikirim frontend ke backend, misalnya email dan password saat login.
Response adalah balasan backend, misalnya token login, data user, daftar slot, atau pesan error.
JSON adalah format data yang paling sering dipakai karena mudah dibaca manusia dan program.
Status code seperti 200, 401, atau 404 membantu menjelaskan hasil request.

Hubungan API dengan keamanan

Tidak semua endpoint boleh diakses semua orang. Karena itu Hygiopark memakai token JWT dan middleware otorisasi. Setelah login, token disimpan di frontend lalu dikirim di header Authorization saat request berikutnya dilakukan. 

api.interceptors.request.use((config) => {
  const token = localStorage.getItem("pw_token");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

Bagaimana Cara Mendevelop Web Parkir Ini

Mengembangkan Hygiopark berarti menyiapkan alat, memahami alur data, lalu bekerja bertahap. Jangan langsung lompat ke fitur besar. Mulailah dari menjalankan project, membaca struktur file, lalu ubah satu bagian kecil agar paham dampaknya.

01

Siapkan tools dasar

Install Node.js, npm, PostgreSQL atau Docker, code editor, dan browser. Ini adalah pondasi agar backend dan frontend bisa dijalankan.

02

Buat environment file

Salin .env.example menjadi .env atau .env.local, lalu isi URL database, secret JWT, dan URL frontend-backend.

03

Install dependency

Jalankan npm install di folder backend dan frontend agar semua library yang tercantum di package.json terpasang.

04

Siapkan database

Jalankan PostgreSQL, lalu gunakan Prisma untuk generate client, migrate schema, dan isi data awal dengan seed.

05

Jalankan backend

Backend menyediakan API, autentikasi, logika reservasi, Midtrans, waitlist, recurring, dan update socket.

06

Jalankan frontend

Frontend React memanggil API backend, menampilkan halaman, menyimpan token login, dan menerima update real-time.

07

Ubah fitur sedikit demi sedikit

Contoh aman untuk latihan: ganti label tombol, tambah field kecil, ubah warna status slot, lalu lanjut ke fitur baru jika sudah paham alur.

Persiapan Praktik untuk Pemula

Kalau halaman ini dipakai sebagai bahan belajar, siswa juga perlu tahu bahwa coding tidak dimulai dari mengetik fitur, tetapi dari menyiapkan lingkungan kerja yang benar. Persiapan yang rapi akan membuat proses belajar jauh lebih lancar dan tidak cepat bingung saat menemui error.

Yang Perlu Disiapkan

Node.js dan npm karena backend dan frontend sama-sama berjalan di ekosistem JavaScript.
Database PostgreSQL atau Docker karena Hygiopark menyimpan data pada database relasional.
Code editor untuk membuka folder project, mencari file, dan mengedit source code.
Browser untuk melihat hasil frontend dan mengetes alur user.
Terminal untuk menjalankan perintah install, migrate, seed, dan dev server.

Yang Harus Dipahami Sebelum Menjalankan

Backend dan frontend berbeda folder, jadi perintah install dan run dilakukan masing-masing.
Database harus aktif sebelum migrasi Prisma dan seed dijalankan.
File env wajib dibuat karena aplikasi membaca URL dan secret dari sana.
Seed penting untuk demo karena akun demo dan data slot dibuat dari script seed.
Login berhasil bukan akhir, tetap perlu cek dashboard, slot, reservasi, dan jika perlu websocket.

Istilah Kecil yang Wajib Dipahami Pemula

Apa itu Prisma?

Prisma adalah ORM. Tugasnya menjembatani kode JavaScript dengan database PostgreSQL supaya query lebih rapi, typed, dan mudah dibaca.

Apa itu PostgreSQL?

PostgreSQL adalah sistem database relasional. Di Hygiopark, ia menyimpan tabel user, slot, reservasi, payment, audit log, dan lainnya.

Apa itu node_modules?

Folder hasil install dependency. Isinya library pihak ketiga. Folder ini besar dan biasanya tidak perlu dijelaskan detail saat presentasi.

Apa itu config?

Config adalah file pengaturan, misalnya koneksi Prisma, Vite proxy, port server, atau Nginx. Config membantu aplikasi menyesuaikan environment.

Apa itu middleware?

Middleware adalah fungsi perantara sebelum request sampai ke controller. Biasanya dipakai untuk cek token, logging, atau pembatasan request.

Apa itu route?

Route adalah alamat endpoint. Contoh: /api/slots untuk data slot atau /api/auth untuk login/register.

Apa itu service?

Service adalah tempat logika bisnis yang lebih kompleks, misalnya menyelesaikan reservasi yang sudah lewat atau memproses waitlist.

Apa itu seed?

Seed adalah script untuk mengisi data awal, misalnya akun demo, lot, slot, reservasi, dan payment supaya aplikasi cepat diuji.

Apa itu real-time?

Real-time berarti data berubah langsung saat ada event baru. Pada Hygiopark, status slot bisa update lewat Socket.IO tanpa refresh halaman.

AI Workflow

Cara berpikir saat memakai AI

Jangan minta "buat aplikasi parkir" secara terlalu umum. Beri konteks folder, file, dan tujuan fitur.
Mulai dari masalah kecil seperti "jelaskan auth middleware" atau "buat halaman presentasi baru".
Minta AI membaca code yang sudah ada sebelum menyarankan perubahan agar hasilnya menyatu dengan project.
Verifikasi hasil AI dengan menjalankan aplikasi, membaca diff, dan mengecek apakah logika bisnisnya benar.
Gunakan AI sebagai partner, bukan pengganti pemahaman. Tujuan akhirnya tetap supaya developer manusia mengerti.

Contoh prompt yang bagus

Saya punya project smart parking dengan frontend React,
backend Express, dan database Prisma PostgreSQL.
Tolong baca struktur folder yang ada dulu, lalu:
1. jelaskan alur reservasi
2. temukan file yang mengatur auth
3. buat perbaikan kecil tanpa mengubah arsitektur

Prompt seperti ini jelas karena menyebut stack, tujuan, dan batasan kerja. AI jadi lebih fokus dan jawabannya lebih relevan.

Pola pikir yang sehat

Pahami dulu masalahnya sebelum menyalin jawaban AI.
Pecah tugas besar menjadi kecil seperti layout, route, API, dan database.
Cek hubungan antar file karena satu perubahan sering berdampak ke route, service, dan tampilan.
Bandingkan jawaban AI dengan code asli agar tidak terjadi halusinasi atau saran yang tidak cocok.
Simpan dokumentasi prompt bila workflow AI ingin diulang atau diajarkan ke orang lain.
